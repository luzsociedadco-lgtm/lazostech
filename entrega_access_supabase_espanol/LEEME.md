# LazosTech para Access — versión en español con datos registrados

Esta copia fue generada el 14 de julio de 2026 desde Supabase en modo de solo lectura. Supabase no fue modificado.

## Archivo principal

- `LazosTech_Supabase_Espanol.accdb`

## Contenido

- Todas las tablas y columnas tienen nombres en español.
- `Estudiantes_Registrados` consolida correos, nombres y datos académicos registrados.
- Se conservan los datos reales disponibles en las tablas públicas y el correo de registro de Auth.
- Se excluyen contraseñas cifradas, tokens, sesiones, direcciones IP, factores MFA y metadatos internos de autenticación.
- Total de estudiantes registrados: 31.
- Total de relaciones: 16.

Los CSV incluidos permiten revisar o reutilizar cada tabla por separado.
